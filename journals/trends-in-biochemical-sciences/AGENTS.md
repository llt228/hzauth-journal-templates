# AGENTS.md — Trends in Biochemical Sciences

本目录是 *Trends in Biochemical Sciences* 的 LaTeX 投稿模板。

- 官方文档类：Elsevier elsarticle
- 官方来源：https://ctan.org/pkg/elsarticle
- 入口：`main.tex`（出版商官方示例，仅设置期刊名/文档类选项）
- 编译：`latexmk -pdf main.tex`

## 约定

- 不要修改 `.cls`、`.sty`、`.bst`、`.cfg` 文件。
- 正文、作者、单位、摘要和文献均为官方示例内容，写作时全部替换。
- 图片放 `figures/`，文献放 `references.bib`。
- `main.pdf` 是编译产物，保留在仓库中供预览。
- 投稿前核对期刊最新的 Guide for Authors。
